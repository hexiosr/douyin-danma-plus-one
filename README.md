# 抖音直播弹幕 +1

抖音直播网页版聊天列表的 +1 脚本：每条普通弹幕后面有一个 +1，点一下自动发送相同内容。


## 功能

- 每条弹幕后面显示 +1
- 点 +1：清空输入框 → 填入原弹幕 → 回车发送，没反应再点发送按钮
- 输入框里有草稿时会先清空
- 写入后被抖音截断（字数上限）时不发送，并提示实际上限
- 往上翻聊天记录时照常加载历史；松手停住后当前画面定格成快照，新弹幕不会再顶动它
- 定格期间可以选中复制、点 +1；继续滚动会交回实时列表，从同一位置接着翻
- 点右下角「回到底部」恢复自动跟随
- 快照是页面内存里的一份列表拷贝，只含定格那一刻已渲染的弹幕（约一到两屏），不写磁盘、不存浏览器存储；刷新或切换直播间即消失

## 安装

1. 安装 Tampermonkey 浏览器扩展
2. [Greasy Fork地址](https://greasyfork.org/zh-CN/scripts/605283) 
3. 点安装即可

## 使用

打开 `https://live.douyin.com/` 任意直播间并登录，点弹幕后面的 +1。
