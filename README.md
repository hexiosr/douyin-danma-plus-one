# 抖音直播弹幕 +1

抖音直播网页版聊天列表的 +1 脚本：每条普通弹幕后面有一个 +1，点一下自动发送相同内容。


## 功能

- 每条普通弹幕后面显示 +1，点击发送相同内容
- 点 +1：清空输入框 → 写入内容 → 回车发送，没反应再点发送按钮
- 写入后检测被抖音截断（字数上限），截断时不自动发送，提示实际上限
- 用滚轮往上翻聊天记录时暂停列表自动滚动，翻回底部恢复

## 安装

1. 安装 Tampermonkey 浏览器扩展
2. [Greasy Fork地址](https://greasyfork.org/zh-CN/scripts/605283) 
3. 点安装即可

## 使用

打开 `https://live.douyin.com/` 任意直播间并登录，点弹幕后面的 +1。

## 已知限制

- 只识别普通弹幕；系统提示、进场、礼物消息没有 +1
- 抖音把弹幕表情渲染成没有文字替代的图片，脚本读不到具体表情，+1 内容不含表情
- 弹幕字数上限由抖音按账号/客户端控制，超限的弹幕不会自动发送
- 发送前会清空输入框里的原有内容
